版本：v3 ｜ 定稿日：2026-09-30 ｜ **本版替代 v2，全部作废 v2 中冲突内容**

## 0. 项目背景与目标
- 域名：ovanto.ai（已购入，全站统一【非 www】）
- 定位：AI 图片 / 视频在线生成工具站，免注册即用
- 首期 7 个页面，覆盖英语 / 意大利语 / 法语 / 荷兰语
- 目标：每页在各自语区 Google 排到目标词前十
- 画像参照：搜索与直访各占约四成（免注册工具的典型结构），首期把「直访可记、可拼」和「首屏可用」做扎实

## 1. 技术栈
- Next.js 14+ (App Router) + TypeScript + Tailwind CSS
- 渲染：**SSG 或 SSR**。禁止纯 CSR——爬虫首轮抓取必须能拿到 Title / Description / H1 与正文
- 部署：Vercel（或 Cloudflare Pages）
- 生成产物走 CDN，不落本地磁盘
- 生成服务：见第 8 节

## 4. 全局 head 标签（每页必须有）
1. <title> / <meta name="description">（用第 3 节值）
2. <link rel="canonical" href="本页绝对 URL">（自指，不得指首页）
3. hreflang —— 每页放全 5 条：
   <link rel="alternate" hreflang="en" href="https://ovanto.ai/">
   <link rel="alternate" hreflang="it" href="https://ovanto.ai/it/">
   <link rel="alternate" hreflang="fr" href="https://ovanto.ai/fr/">

   ⚠️ /fr/photo-ia-gratuit 与 /fr/modifier-photo-ia **不放 hreflang 互指**
      （无对应语言版本），只与 /fr/ 做内链关联
4. <html lang="xx"> 按页面语言（en / it / fr / nl）
5. Open Graph + Twitter Card（og:title / og:description / og:image / og:url / og:type）
6. 结构化数据：根页与各语区首页用 WebApplication；FAQ 段落用 FAQPage
7. ⚠️ 不写 <meta name="keywords">

## 5. 首屏与工具本体（每页同结构，文案按语言替换）

5.0 信息顺序固定，不得调整：
  1. H1（定稿文案，一字不改）
  2. 三个信任点（横排，移动端换行）
  3. 工具本体
  4. 示例区（3 张，alt 写清内容）

5.1 信任点定稿（**禁止 100% Free / Unlimited**）
  en: Free: 3 images/day · No sign up · Video 5s from $0.99
  it: Gratis: 3 immagini al giorno · Senza registrazione · Video 5s da $0.99
  fr: Gratuit : 3 images/jour · Sans inscription · Vidéo 5s à partir de 0,99 $
  nl: Gratis: 3 afbeeldingen per dag · Geen registratie · Video 5s vanaf $0.99

5.2 工具本体控件（首期只做这 3 个，不得增加）
  - prompt 输入框
  - 生成按钮（**按钮旁显示本次消耗**：免费档 "Free (3/3 today)"，付费档 "$0.99"）
  - 结果区（含下载按钮）
  ⚠️ 不要现在抄对标站的 7 个控件（模型/比例/数量/分辨率/质量/风格/reference），
     等付费档上线再逐级加

5.3 首屏配比
  - 桌面端 H1 最多 2 行，字号降一档；工具本体是首屏视觉重心
  - 移动端 375×667 首屏必须可见输入框与生成按钮（Phase 1 已通过，改动后需回归）

5.4 交互要求
  - 不得弹注册框、不得要求登录 / 邮箱 / 信用卡
  - 生成中要有 loading 态，失败要有明确错误提示
  - 结果区要有下载按钮；免费档图片不加水印，付费档可去水印由配置决定

5.5 用户可见文案禁令（详见第 13 节）
  - 不得出现 "Phase 1" / "Anteprima" / "segnaposto" / "non ancora collegata"
    等开发语境字样
  - 不得出现禁用的假按钮、虚线占位框

5.6 信任点以外的免费表述
  - Title / Description / H1 中的 gratis / gratuit / Free / Gratis **一律保留**
    （核心词字面含「免费」，删即放弃排名）
  - 「免费」的兑现方式是免费档额度，不写模糊的「完全免费」
