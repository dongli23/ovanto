# Ovanto.ai v4 — Phase 2 本地实现与验收边界

权威文件：`docs/ovanto-brief-v4.txt`。本报告替代 v3 的当前工作状态记录，v3 报告保留为历史证据。

## 已实现

- 七个 SSR 路由及四语言固定 SEO 文案、canonical、hreflang、H1/H2、信任点与内链矩阵。
- 两个法语内页提供原图上传、缩略图及 Kontext 编辑；其余五页不出现上传控件。
- 免费图片 / 编辑 / 视频分别为 3 / 1 / 1 次每 IP 每 UTC 日；Turnstile、可信 IP/国家识别、IN/RU 免费限制。
- Redis Lua 原子预占三个独立成本池 $3 / $2 / $5，同时检查单独的总额 $10；包含处理中请求，明确拒绝才释放，异常提交保守保留。
- 免费模型 Flux Schnell、Kontext Dev、Wan 2.5；付费模型 Flux Dev、Kontext Pro、Kling 2.5 Turbo Pro。视频固定 5 秒；免费 480p。未启用 Veo 或 v2 模型。
- 10,000,000 字节上传上限，浏览器直传签名 CDN。服务端验证实际 MIME、文件签名、Sharp 解码、所有权/IP，再复制到独立 CDN 对象，防止验证后覆盖原文件。无图片落盘。
- Stripe Guest Checkout、原始 webhook 验签、同事务订单/额度/邮箱账号、事件和 session 幂等；密码免设，激活链接和八位邮箱验证码。
- 回跳自动登录只授予本次订单权限；邮箱验证后才能访问历史账号额度，防止填写他人邮箱盗用旧额度。
- 付费额度先事务预占再提交模型；明确拒绝释放一次，异常提交保留任务与幂等键，不自动重复扣费。
- 加密邮件 outbox，稳定发送幂等键和失败重试。代码只记录预计供应商成本，不把它声称为实际账单。

## 配置和未确认项

`.env.example` 列出了供应商、Turnstile、Upstash、Stripe、PostgreSQL、Resend 与独立账号密钥。当前没有真实配置；付费目录因此关闭，免费生成显示暂不可用，不绕过校验。

数据库迁移：`scripts/sql/001_payments_accounts.sql`。生产 PostgreSQL 要求校验证书的 TLS。数据库/邮件方案尚待确认，未创建外部服务、未应用生产迁移。

图片与编辑零售价尚待确认；Kling 5 秒零售价须在 $0.99–1.49 范围内配置。10 秒选项没有开放。不能把模型成本当作用户价格。

上传另有技术保护：每 IP 十分钟最多 5 次、50 MiB，与生成额度独立。CDN 对象与上传资产一小时过期。

按 $0.023 预算计算，$2 编辑池可接受 86 次，第 87 次将超过 $2；文档中的约 87 次没有被当作越过预算的授权。
