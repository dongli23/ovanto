你是这个项目的执行工程师。本文档中所有 URL、Title、Description、H1、H2 均为已定稿内容，

## 0. 项目背景
- 域名：ovanto.ai（已购入，全站统一【非 www】）
- 定位：AI 图片 / 视频在线生成工具站，免注册即用
- 首期上线 7 个页面，覆盖英语 / 意大利语 / 法语 / 荷兰语
- 目标：每一页在各自语区的 Google 排到目标词前十

## 1. 技术栈（如无异议按此实现）
- Next.js 14+ (App Router) + TypeScript + Tailwind CSS
- 渲染方式：**SSG 或 SSR**。禁止纯 CSR —— 爬虫首轮抓取时必须能拿到 Title / Description / H1 和正文
- 部署：Vercel（或 Cloudflare Pages）
- 图片生成结果用 CDN，不要本地存
- 生成接口：`[[GENERATION_API]]`（待用户填入，Phase 2 前必须确认）

## 4. 全局 head 标签（每页都必须有）

1. <title> / <meta name="description"> —— 用第 3 节的值
2. <link rel="canonical" href="本页绝对 URL">（自指，不能指首页）
3. hreflang —— **每页都放全这 5 条**，值固定：
   <link rel="alternate" hreflang="en" href="https://ovanto.ai/">
   <link rel="alternate" hreflang="it" href="https://ovanto.ai/it/">
   <link rel="alternate" hreflang="fr" href="https://ovanto.ai/fr/">
   <link rel="alternate" hreflang="nl" href="https://ovanto.ai/nl/">
   <link rel="alternate" hreflang="x-default" href="https://ovanto.ai/">
   ⚠️ /fr/photo-ia-gratuit 与 /fr/modifier-photo-ia **不要**放 hreflang 互指
      （无对应语言版本），它们只与 /fr/ 做内链关联。
4. <html lang="xx"> 按页面语言设置（en / it / fr / nl）
5. Open Graph + Twitter Card：og:title / og:description / og:image / og:url / og:type
6. 结构化数据：根页和各语区首页用 WebApplication，各页 FAQ 段落用 FAQPage
7. ⚠️ **不要写 <meta name="keywords">**

## 5. 首屏与工具本体（每页同一结构，文案按语言替换）

从上到下：
1. 页头：左侧 Logo "Ovanto"，右侧语言切换器（4 个 <a href> 硬链接）
2. H1
3. 一句话价值说明（= Title 核心词的自然改写）
4. **工具本体**：一个输入框 + 一个生成按钮 + 结果区
5. 三个信任点（横排小图标）：无需注册 / 完全免费 / 数秒出图
6. 下方接第 3 节的 H2 正文内容
7. 页脚：版权 + 链出 4 个语言首页

工具本体的硬性要求：
- **不得弹注册框、不得要求登录、不得要求邮箱**。点生成就出结果
- 结果区要有下载按钮
- 生成中要有 loading 态，失败要有明确错误提示
- 首屏（不滚动）就能看到输入框和按钮
